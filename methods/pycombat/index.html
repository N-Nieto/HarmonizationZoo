Get started

Install bash

pip install pycombat

Usage python

from pycombat import Combat

combat = Combat()
combat.fit(Y=Y, b=b, X=X, C=C)      # Y: [observations x features], b: batch labels
Y_adjusted = combat.transform(Y=Y, b=b, X=X, C=C)
